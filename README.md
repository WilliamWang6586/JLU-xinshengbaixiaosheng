## 🎯 高频问答速查

- **转专业（2026）**：GPA≥3.0，笔试只考数学（微积分BI+高中数学），总成绩=(50%笔试+50%面试)×志愿系数（一志愿100%）
- **2025对比**：笔试曾考数学+英语两科、面试定胜负 → 2026改为只考数学、笔试面试各50%
- **吉大GPA**：∑(学分×绩点)/∑学分，95-100→4.0，84-86→3.0，重修取最高分
- **英语分级考试**：高考题型+四级难度-短文改错-七选五+段落汉译英，决定A/B/C班
- **2024流动数据**：汽车工程学院转入148人（全校第二）、交通学院转出101人（全校最多）
