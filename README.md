## 🎯 高频问题速查

**转专业到车辆工程（2026最新）**：接收44人；GPA ≥ 3.0；笔试只考数学（微积分BI+高中数学）100分、单科≥60；进面试=大一笔试前50名/大二前17名；总成绩 = (50%笔试 + 50%面试) × 志愿系数（一志愿100%/二志愿90%/三志愿80%）。政策逐年变化：2025年考数学+英语且面试定胜负，2026年改为只考数学、笔面各占50%。

**哪些专业转专业要考 C 语言**：2026 年全校**只有人工智能学院**考。计算机学院/软件学院笔试考的是《微积分AI》，不考 C —— 这是最容易搞混的一点（课程要求 ≠ 笔试科目）。

**转过去要补多少课**：大一上 27.5 学分里 26.5 分两边必修 100% 认定，仅 1 分导论作废；真正要补的只有约 3 学分（制图类）。车辆总学分 158 比交通运输 169 还少 11 分，学分账完全覆盖。真正的风险是**门槛账**（GPA 与排名），不是补课。

**吉大 GPA 计算**：∑(课程学分×课程绩点)/∑课程总学分；95-100→4.0、90-94→3.7、84-86→3.0、64以下→0；重修取最高分不累加。

**英语分级考试**：听力20分+阅读+词汇结构+完形+翻译+写作，难度约四级（词汇4000-4500），成绩决定英语A/B/C班。

**宿舍校园网**：20元/月/IP不限流量（2月7月免费）；上网账号=吉大邮箱账号+邮箱密码（不是学号！）；宿舍有线需登记网卡MAC、自动获取IP；同时在线上限1台PC+2台移动设备。宿舍 A 类 IP 无国际出口，境外站点需走镜像加速（详见 `wangzhan_all.txt`）。

**保研**：常规推免/专项计划/补偿名额/校际互推四途径；大一绩点英语→大二科研竞赛→大三论文夏令营→大四收获。2027 年起推免比例 ≤50%、复试 60 分合格。

**想进车队**：吉大共 5 支车队，10 月发宣传片招新。吉速是 FSC 创始队之一（2009），2025 年七冠王六连冠。FSC 总分 1000 分里 175 分是成本/商业报告类分数 —— **技术不强也能从商业组切入**。

**某专业好不好就业**：学校不按专业公布就业去向，只能拿就业网在架岗位反推。方法与实测薪资区间见 `jlu-employment-data-method.md`。
