## 附：程序改错常见错误类型总结

| 错误类型 | 例子 |
|---|---|
| 初始值错误 | `p=0` 应为 `p=1`、`k==1` 应为 `k=1` |
| 循环边界错误 | `range(1,n)` 应为 `range(1,n+1)` |
| 整除/取余混淆 | `num/=10` 应 `num//=10`、`r/1000` 应 `r%1000` |
| 逻辑运算符错误 | `or` 应 `and`（"同时"） |
| 缺类型转换 | `input()` 应 `int(input())` |
| 计数错误 | `n=n+i` 应 `n=n+1` |
| 缺函数定义 | 补 `def isPrime(n):` 等 |
