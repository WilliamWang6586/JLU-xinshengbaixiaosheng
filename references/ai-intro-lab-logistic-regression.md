第⼀部分 · 知识地图  
第⼆部分 · 知识点精讲  
1. 逻辑回归是什么（★必背）  
名字带「回归」，实际是分类算法，且是有监督学习（训练数据有标签 0/1）。
先把特征做线性组合 z = w₁x₁ + w₂x₂ + … + b，再过⼀个 sigmoid 函数，把任意实数 z 压到 (0,1) 区
间，当作「属于正类的概率」。
预测时 概率 ≥ 0.5 → 1（通过），否则 0（未通过）。注意：模型原始输出是概率，不是类别，类别是拿
阈值 0.5 切出来的。
2. sigmoid 函数（★必背）  
值域 (0, 1)（开区间，取不到 0 和 1）——这是它能把「分数」变成「概率」的关键。
单调递增，σ(0)=0.5，z→+∞ 时 →1，z→-∞ 时 →0。
对应题库考点「逻辑回归模型输出结果范围通常是 [0,1]」。
3. 交叉熵损失（★必背）  
⼆分类交叉熵（对数损失）：
y_i 是真实标签（0/1），p_i 是预测概率。
为什么不⽤均⽅误差（MSE）？ sigmoid + MSE 的梯度⾥含 σ'(z)，当 σ 接近 0/1 时梯度趋近 0（梯度消
失），且损失⾮凸、易陷局部最优；交叉熵的梯度恰好消掉 sigmoid 的导数项，梯度⼲净、凸性好。→ 简答
逻辑回归（⼆分类，有监督学习）
├─ 模型：z = w·x + b ──sigmoid──► σ(z)=1/(1+e⁻ᶻ) ∈ (0,1)  输出"正类概率"
├─ 决策：概率 ≥ 0.5 判为正类（通过），否则负类（未通过）
├─ 损失函数：交叉熵（⼆分类）  L = -mean[y·log p + (1-y)·log(1-p)]
├─ 优化：梯度下降  w←w-lr·∂L/∂w ，b←b-lr·∂L/∂b
├─ 预处理：StandardScaler 标准化（fit 只在训练集上做）
├─ 评估：准确率 / 精确率 / 召回率 / F1 / 混淆矩阵
└─ 两版实现：sklearn LogisticRegression  vs  NumPy ⼿写梯度下降
  预测=通过(1) 预测=未通过(0)
真实=通过 TP（真阳性） FN（假阴性，漏判）
真实=未通过 FP（假阳性，误判） TN（真阴性）
题常考。
4. 梯度下降（★必背）  
对参数求偏导，沿负梯度⽅向更新：
令 error = p - y（概率减标签），则 dw = mean(error·x)，db = mean(error)。
更新：w ← w - lr·dw，b ← b - lr·db，lr 是学习率（步⻓）。
两个超参数：learning_rate=0.1、iterations=2000。2.py ⾥ dw1~dw4 就是把 4 个特征的梯度分别
算出来再合并成 dw 数组。
5. 标准化 StandardScaler（★必背，易错点）  
公式：(x - mean) / std，让每个特征变成均值 0、⽅差 1 的量纲，避免「上次考试成绩(4095)」和「学习时
间(0.55)」尺度不⼀致影响梯度。
fit_transform 只⽤在训练集；测试集和新样本只能⽤训练集算好的 mean/std 做 transform。
为什么？若测试集⽤⾃身的均值⽅差，等于偷看了测试集分布（数据泄漏），且模型是在训练集尺度上学的，
必须⽤同⼀把尺⼦。
6. 评估指标（★必背）  
以「通过考试(1)」为正类，混淆矩阵：
准确率 全部 精确率 召回率
精确率：预测为「通过」的⼈⾥，真通过的⽐例（预测准不准）。
召回率：真「通过」的⼈⾥，被找出来的⽐例（找得全不全）。
两者常此消彼⻓（阈值调⾼→精确率升、召回率降）。

第四部分 · 实测结果对⽐（本次实验最值钱的⼀段）  
运⾏实测（random_state=42 固定，结果可复现）：
★ 为什么⼿写版指标反⽽更⾼？指标⾼ ≠ 模型更好  
1. 正则化差异：sklearn 的 LogisticRegression 默认 C=1.0，等价于 L2 正则，会主动把权重往⼩压，防⽌
过拟合；⼿写版没有正则，权重可以⽆约束地⻓（看权重列，⼿写版每个都更⼤）。
2. 迭代与收敛：sklearn ⽤ max_iter=1000 内部优化求解，到⼀定精度就停；⼿写版硬跑 2000 次梯度下降，
把训练损失⼀路压到 0.2739。
3. 后果：⼿写版召回率 = 1.0（把 27 个「通过」学⽣全部找对，1 个都不漏），看起来更漂亮——但它是靠"激
进拟合"换来的，在测试集上可能轻微过拟合，泛化到新数据未必更好。sklearn 版带正则、更稳健。
4. ⼀句话：⼿写版赢在测试集数字，sklearn 版赢在稳健性；单看准确率 0.9167 > 0.8833 就下结论"⼿写更
好"是错的，要结合正则、迭代次数、过拟合⼀起看。

选择题  
1. C　sigmoid 把任意实数压到开区间 (0,1)，习惯上写作 [0,1]。sigmoid 单调递增、σ(0)=0.5。
2. C　逻辑回归是有监督学习（需要标签 0/1）；DBSCAN、K-Means、PCA 都是⽆监督学习。
3. A　"过于简单→⽋拟合"；"过度拟合训练集噪声→过拟合"（对应填空题第 3 题）。
4. A　sigmoid 的核⼼作⽤是映射到 (0,1) 表示概率；B/C/D 都不是它的功能。
5. B　⼆分类逻辑回归⽤交叉熵；MSE 会有梯度消失和⾮凸问题。

判断题  
1. ✗✗✗✗　逻辑回归可通过 one-vs-rest（⼀对多）扩展成多分类（sklearn 的 LogisticRegression 默认就⽀持多
分类）。
2. ✗✗✗✗　原始输出是概率，predict_proba 拿概率，predict 才是类别（内部⽤ 0.5 阈值切）。
3. ✗✗✗✗　测试集必须⽤训练集的均值/⽅差 transform，否则会数据泄漏、且与训练尺度不⼀致。
4. ✗✗✗✗　调阈值时⼆者通常此消彼⻓（提⾼阈值→精确率升、召回率降）。
5. ✗✗✗✗　要结合正则化、迭代次数、是否过拟合判断；本实验⼿写版⽆正则 + 多迭代，指标⾼但可能过拟合（⻅第
四部分）。
简答题  
1. 流程：特征 → 线性组合 z=w·x+b → sigmoid 得概率 p=σ(z) → 阈值 0.5 判类别（p≥0.5 为 1，否则 0）。
训练时⽤交叉熵损失 + 梯度下降更新 w、b；预测前还要⽤训练集标准化的规则 transform。
2. 要点：① sigmoid + MSE 的梯度含 σ'(z)，在两端趋 0，易梯度消失；② MSE 是⾮凸的，可能陷局部最优；③ 
交叉熵梯度恰好消掉 sigmoid 导数项，梯度⼲净、是凸函数，收敛更好。
3. 要点：fit_transform = 先 fit（算训练集的 mean/std）再 transform（套⽤）；transform = 只套⽤已有 
mean/std。测试集/新样本只能⽤训练集的 mean/std，因为模型是在训练集尺度上学的，必须⽤同⼀把尺
⼦，否则数据泄漏。

y=np.array([0.0,0.0,1.0,1.0,1.0])
w=0.0
b=0.0
lr=0.1
for i in range(1000):
    z=x*w+b
    p=1/(1+np.exp(-z))
    err=p-y
    dw=np.mean(err*x)
    db=np.mean(err)
    w=w-lr*dw
    b=b-lr*db
print(w,b)
from sklearn.metrics import accuracy_score,precision_score,recall_score,f1_score
# 还原：TN=27个(0,0)，FP=6个(0,1)，FN=1个(1,0)，TP=26个(1,1)
y_true=[0]*27+[0]*6+[1]*1+[1]*26
y_pred=[0]*27+[1]*6+[0]*1+[1]*26
print(accuracy_score(y_true,y_pred))
print(precision_score(y_true,y_pred))
print(recall_score(y_true,y_pred))
print(f1_score(y_true,y_pred))
