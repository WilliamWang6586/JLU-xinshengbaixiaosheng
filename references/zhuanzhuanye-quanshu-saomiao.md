# 全书扫描法：从 168 页多学院细则汇总里提取「某类考核科目/门槛」（2026-10-23 实战）

场景：用户问「哪些专业转入要考 X」（C 语言、机试、物理、绘画…）。别靠翻关键词命中行猜归属，也别只查几个自己熟悉的学院。

## 一、抽取科目（先定权威源）

唯一权威 = `_extracted\转专业文件_吉林大学各学院2026年本科生集中考核转专业工作实施细则汇总 (1).pdf.txt`（4838 行 / 168 PDF 页，40+ 学院）。

**两步定归属**（缺一不可）：
1. `re.search(r"C\s*语言|Ｃ语言|程序设计|编程|上机|机试", line)` → 只捞到 3 行，全在人工智能学院。
   单靠这步无法确认「只有它一家」——还要反查别家的笔试科目叫别的名字。
2. 按页切块，只留含 `笔试|初试|机试|考核方式|考试科目|考核科目` 的页，逐页读 **「考核方式 / 笔试 / 考试科目」那几行**，把每家真实科目抄下来。

## 二、页面 ↔ 学院归属

PDF 页眉 `— N —` 是印刷页码（比 PDF 物理页少 2），**别拿它算行号**。定位学院标题用：
`re.search(r"2026\s*年.*(转专业|集中考核).*细则", s) and "各学院20XX" not in s and len(s) < 45`
（标题会在两行断开，如 `…工作实施` / `细则`，所以用宽松正则 + 就近读 40-60 行才稳。）

## 三、时效核实（用户问「有没有更新的政策文件」时的标准动作）

1. **链接表批量探测**：`_extracted\转专业文件_2026各学院细则链接.txt` 表格（`|` 分隔）里有 43 个 `学院实施细则链接`，`ThreadPoolExecutor(12)` + 15s 超时并发跑，看 HTTP 码 + `<title>` 里的年份。2026-10-23 实测：41 个 200 仍是 2026 版，2 个 404（基础医学院、食品学院）——404 不影响结论，正文在汇总 PDF 里。
2. **重点院官网**：细则页本身带「上一篇/下一篇」，能顺藤摸到排名公示等后续文件；学院 `tzgg.htm` 列表页有日期，可判「细则之后有无新版」。
3. **本科生院**：`https://jwc.jlu.edu.cn/` 首页可读，**但 `/tzgg.htm` `/index/tzgg.htm` 全 404**；通知正文路径是 `/info/1050/<id>.htm`，教学公示栏目 `list.jsp?urltype=tree.TreeTempUrl&wbtreeid=1402`，规章制度-学籍管理 `wbtreeid=1384`（转到旧版《暂行办法》校发〔2022〕264号 的 `content.jsp?...wbnewsid=11385`，**那是过期版，现行是校发〔2024〕201号**）。
4. **弄清公示是哪个通道**：2026-10-20「万相成等101名拟调整专业」（校本院字〔2026〕76号）= 优势专长29 + 唐敖庆班69 + 退役复学2 + 专业特长1，属 **特殊类型转专业（9月那批）**，与集中考核转专业无关。看到「转专业公示」先读正文分类，别当成新一年的集中考核通知。
5. **年份节奏**：2026 年那轮 = 2025-12-12 下发通知 → 12-31 各院公示细则 → 次年 3 月报名考核。所以 10 月问「有无更新」的正确答案是「无，等 12 月中下旬」。

## 四、输出格式（用户要「核实时效」时的答法）

先一句结论（「没有更新的，手上这份就是最新」）→ 核实方法表（检查项 | 结果）→ 容易被误导的两点 → 下一个变化时间点。别把 168 页的扫描过程铺给用户看。
