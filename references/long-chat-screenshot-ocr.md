# 超长聊天截图转录（QQ/微信长截屏）

## 症状

用户发来的聊天记录截图**高度上万像素**（实测 1240×9616），视觉接口直接报
`unsupported image format` 或缩到 1600px 后文字全糊。

## 步骤

1. **先看尺寸**，不要直接喂视觉接口：

```python
from PIL import Image
im = Image.open(p); print(im.format, im.size, im.mode)
```

2. **按高度切段**，每段约 1200–1600px 高，段间留 40px 重叠避免切断气泡：

```python
w, h = im.size; n = 6; step = h // n
for i in range(n):
    box = (0, max(0, i*step-40), w, min(h, (i+1)*step+40))
    im.crop(box).save(rf'...\chat_{i}.jpg', 'JPEG', quality=90)
```

3. **逐段调用 `vision_analyze`**，问同一句话：
   「逐条转录所有对话内容，注明谁说的（左/右侧气泡）、时间」

4. **拼接时注意**：视觉模型会把聊天软件认错（QQ 截屏说成 WeChat），
   **只认气泡左右和时间戳**，软件名不可信。

5. 环境变量 `$env:PYTHONUTF8='1'`，`py -c` 里写中文路径可以，
   但复杂逻辑还是写 .py 文件更稳。

## 回答时的转化

用户发聊天记录通常不是要「转录」，是要**「我该怎么回」**。交付结构：

1. 表格：对方关键信息 → 对你的意义
2. **可直接复制粘贴的回复草稿**（放代码块或引用块里）
3. 为什么这么回的 2–3 条理由
4. 顺带一问（能探出下一条关键信息的那个问题）

**不要**只给转录结果，也不要把每条消息都复述一遍。
