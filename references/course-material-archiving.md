# 课程资料归档与消化（同学分享的课件/题库/教辅包）

触发：用户扔来桌面/微信/网盘的一个课程资料文件夹，说「帮我归档到你的文件夹里面，并阅读相关内容」。
本文件以 **人工智能引论 A（2026 秋）** 为完整样本，方法对任何课通用。

---

## 一、归档目录约定（学习类课程统一放这里）

`<本地资料库>`

```
<课程名>\
├─ 课件\                    ← 官方 PPT/PDF，原文件名不动
├─ 同学资料_题库与教辅\        ← 同学/群里转来的 md、题库、教辅
├─ <课程名>_期末复习讲义.md/.docx/.pdf   ← 自己做的（若有）
├─ 资料总览与复习重点.md       ← 每次归档后必须产出这一份
└─ _check/ _pages/ _extracted/ OCR/  ← 历史脚本中间产物，保留不动
```

要点：
- **先 `search_files target=files` 看目标目录现状**，别急着建新目录。
- **课程名以用户给的名字为准**。本课官方叫「人工智能引论 A」，但库里旧目录是「人工智能导论」——同名课两个目录会长期混淆。判断：用户桌面文件夹名 = 他/课表的叫法 → 用它建新目录，且在回复里一句话点明「旧目录叫 XX，这次按你给的 YY 新建」。
- 桌面原件**不删不改**，只 copy。
- 归档后 memery 里必须留指针（含**准确的目录名**，`引论` vs `导论` 写错等于记忆失效）。

## 二、归档动作（可复用 PowerShell 片段）

```powershell
$src="<桌面>\<课程>"; $dst="<本地资料库>
New-Item -ItemType Directory -Path "$dst\课件","$dst\同学资料_题库与教辅" -Force | Out-Null
Get-ChildItem $src -File -Filter *.pptx | Copy-Item -Destination "$dst\课件\" -Force
Get-ChildItem $src -File -Filter *.md   | Copy-Item -Destination "$dst\同学资料_题库与教辅\" -Force
# 逐个 MD5 校验（Copy 完必须验，别只信 exit code）
```

⚠️ 本机 terminal 里 PowerShell 命令**即使全部成功也常返 exit_code=1**（`$LASTEXITCODE` 被最后一条管道污染），
别把它当失败去重试。**判定成功只看输出内容 + 落地文件**：
```powershell
cmd /c "chcp 65001 >nul & dir /b /s ""D:\...\目录"" "
```
`search_files` 对新建的中文子目录可能报 *Path not found*（缓存/编码），用 `cmd /c dir` 复核最稳。

## 三、读什么、怎么读（按投入产出排序）

一篇 5000 行题库不要逐行 read。顺序：

1. **盘点文件 + 行数 + 首行标题**（一条 PowerShell 循环搞定），先知道体量与结构。
2. **分析型文件先读**（`*分析报告*`、`README`）——它已经把统计做完了，直接拿结论。
3. **速记型文件全读**（`*背诵卡片*`、`*知识点*`，通常 200-350 行)——这是能直接背的成品。
4. **大题库只读目录 + 抽样**：`search_files pattern="^#{1,3} "` 出全文目录（看每章题量），
   再读每章前 30 行看题干/答案格式，判断质量。
5. **教辅抽读开头 40 行**——看它有没有「知识地图 + 精讲 + 习题」结构，有则只作索引不入正文。

## 四、交付物：`资料总览与复习重点.md`（固定七节）

1. 文件夹结构树（标出每份资料是什么、缺哪块）
2. **同学这套资料到底给了什么**（含金量评级表 + 唯一要警惕的坑）
3. 题量/体量结构化统计表（按章、按题型，给百分比）
4. 高频考点 Top N（带频次）
5. 必须背死的硬骨头（表格化，能直接背）
6. 复习优先级（「只剩时间做三件事」）
7. 结尾一句：下一步能帮他做什么（如「把程序题按你现在的进度挑一套练习」）

用户偏好（已多次验证）：**先说人话结论**（「真正有价值的是那份 882 题题库——等于考试范围全知道了；但答案是 OCR 抄的，有错字」），
再上表格证据；全中文；忌首尾复述；表格要「与要求一一对应」。

## 五、⚠️ 二手资料质量门禁（本类任务最重要的坑）

同学转来的题库/教辅 99% 是**扫描件 OCR 出来的**，两类错误必须主动向用户指出：

| 错误类型 | 实例（人工智能引论 882 题） |
|---|---|
| OCR 错字 | 「人形机**諾**人」→ 人形机器人；「**妻**根鲍姆」→ 费根鲍姆；「菜登伯格」→ 莱德伯格 |
| OCR 错词/错数字 | 「模型**制程**」→ 模型效率；「精**細**化」→ 精细化 |
| **标答本身是错的** | 第1章第11题「人工智能三要素不包括」，标答给 C（算法），实际三要素=数据/算力/算法，正确答案是 A（硬件） |

结论口径：**背概念以课件/背诵卡片为准，题库只用来记「这题考什么、怎么出题」**。写进总览文件的「含金量」表里，别只在聊天里说一句。
