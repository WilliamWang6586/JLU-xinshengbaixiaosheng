# 吉大考试时间 / 考核方式查询

## 一句话

期末、期中考试安排**只在 OA 发**，且正文表格是图片。教务处、考试中心网站都查不到。

## 各站点实际职责（实测 2026-11）

| 站点 | 实际内容 | 有没有用 |
|---|---|---|
| `oa.jlu.edu.cn` | 校内通知正文 | **唯一权威源**，免登录可读 |
| `jwc.jlu.edu.cn/fwzn/xs1/ksap.htm` | 「考试安排」栏，只有零散单科/重修/思政课通知 | 最新一条常滞后一学期，用处小 |
| `jwc.jlu.edu.cn` 校历 | 只挂到 2020-2021 学年 | 没用 |
| `kszx.jlu.edu.cn` | 四六级、JLPT、TOPIK、NCRE 等**国家考试** | 与校内期末无关 |
| `jt.jlu.edu.cn`（学院） | 人事、组织、党建通知为主 | 基本没有教务 |

**期中考试不在任何网站**。微积分等公共课期中由数学学院/任课教师自行安排，只在课堂、班群、课程群通知。教务系统（iedu）登录后"我的考试"才有。

## OA 正文抓取步骤

```python
u = ('https://oa.jlu.edu.cn/defaultroot/PortalInformation'
     '!getInformation.action?id=71764826&channelId=179577')
r = requests.get(u, headers={'User-Agent': '...'}, timeout=25, verify=False)
r.encoding = 'utf-8'
body = re.sub(r'<script.*?</script>', '', r.text, flags=re.S)
body = re.sub(r'<style.*?</style>', '', body, flags=re.S)
lines = [l.strip() for l in re.sub(r'<[^>]+>', '\n', body).split('\n') if l.strip()]
```

- 页面里混着大段登录框 JS（RSA 加密那段），必须**先剥 script/style**，否则全是噪音。
- 标题/日期/发文单位在 `lines[205:215]` 附近，往前找含"期末考试""通知"的行更稳。
- `&ensp;` `&nbsp;` 会留在文本里，展示前替换掉。

## 表格是图片，必须走视觉

```
/defaultroot/upload/html/20261104084726567.png   ← 表1（2026级公共基础课）
/defaultroot/upload/html/20261104084744250.png   ← 表2（其他年级/课程）
```

下载要点：带 `Referer: https://oa.jlu.edu.cn/`，校验 `content[:4] == b'\x89PNG'`。
这些表格线框清晰、印刷体，`vision_analyze` 一次就能完整转录，不会编造。**要求"逐行逐列完整转录，含表头，不要遗漏"**。

## 正文里的隐藏金句

通知正文常夹带比考试时间更重要的管理信息。例：

> 因本学期期末考试成绩涉及 2026 级本科生转专业（类）工作，要求各教学单位于 **2027 年 1 月 29 日前**务必将 2026 级所有学生成绩录入教学管理系统。

→ 读这类通知时，**通读全文，不要只提取日期表**。

## 考核形式（开卷/闭卷）的准确口径

- 通知里**从不写**。检索"闭卷/开卷/考核方式"在 OA 正文中命中数为 0。
- 依据 `校教字〔2020〕123号`《吉林大学本科课程考核管理办法》，考核形式由**任课教师**确定。
- 可靠推断范围：数学公共课（微积分、线代）闭卷 2h；大学英语闭卷含听力；思政类（习思想、军理、国安、形策）多为开卷/一页纸/线上，**每年每门都可能变**。
- 结论：除数学英语外，一律答"以课程群通知为准"，不要替学校下结论。

## 时长

校内期末统一 **上午 9:00-11:00 / 下午 13:00-15:00**，每场 2 小时。期中沿用同一考务标准。
