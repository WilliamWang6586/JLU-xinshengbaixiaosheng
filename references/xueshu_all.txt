国内本科—海外升学 VS 海外本科—海外升学
总体而言，海外本科申请海外研究生要比国内容易很多
·区别一：英语。大部分海外高校规定，在英语为母语的国家读书2年或以上，并且获得本科学位的学生，可以免试托福雅思。
海外本科生无需考托福，有更多时间备战GRE，这是巨大优势。
·区别二：规划老师。在许多海外大学，本科生一入学就会被分配学业指导老师，会提供升学咨询，而国内这部分很弱。
·区别三：推荐人。申请国外大学时，通常都需要学生提供教师的推荐信。对海外本科的学生来说，这不是什么问题，因为老
师也是外国人，但对国内的学生而言，推荐信一般只能靠自己的中国老师来书写，要是老师知名度不是太高，就难以出彩。
·区别四：学校背景。本身就在海外大学念书的人，申请海外研究生自然也更容易，因为语言、文化和学校背景等都比较契

科研本身的目的是在于创造新的东西，如果不质疑前人的眼光和视野，就不能发现新
的问题。
现在的科研更多的是多领域结合的创新，要完完全全革命式的创新非常难，因此需要
将各个不同的课题和学科之间寻找彼此的联系，把看似不同的方法和事物建立关联，
才能发现问题所在。
为了更好地完成科研任务，首先需要有扎实的专业基础知识，其次需要有快速补给新
知识的快速学习及应用能力。
每天需要阅读大量的文章信息，行业信息和专业信息，应该养成每天读2-3 篇文献的
习惯，只有快速阅读文献，才能够跟进最新动态，有所产出。
需要接触的内容非常多，因此需要迅速的将现有的资料进行归纳总结，拿出现有科研
成果的发展路线图，从而提出自己的解决方案。
科研研究方向是基于假设的，在做分析的时候，要求不管最终的实验结果是否支持你
的假设，你都能基于这个结果开展下一阶段的研究。所以在提出假设的时候必须逻辑
严密（不管结果好坏，都能够发文章）。
（仅理工科）除了自己动手搭试验台，还要自己动手做试样，设计实验之后要通过动手实
验来验证，那基本的动手实验能力也是必须的。
（文商科）需要设计访谈调研，并且付诸实施。
发文章是一件长期的事情，需要承受着好几年过去了还没有文章的精神压力，也有
可能做了几年实验还是失败发不出文章，因此读博期间放弃或者精神崩溃都是常见
的事情。
实验的过程要是数据收集和分析的过程，要对异常数字保持敏感度。
对外演讲，参加学术会议、报告展示等，你的口头表达能力良好，会很占优势，能够清
楚的讲明白自己做了什么，也能让人及时抓住你的重点。
如何把自己做出的成果表达出来，就需要我们拥有过硬的写作能力。将清晰的思路完
整的写出, 然后分析数据，完整书写。

保研流程
学校会综合考虑学业成绩+学术成果+社会实践。其中学术成果指的是须提交已发表论文

可能会涉及最近关注的研究领域、成果、思考

举个例子来看一下，常见院校在确定保研录取名额时候的加分项怎么算
1、工作获奖：三好学生，分数在0.5-5分不等
2、奖学金：分数在0.5-4分不等
3、科研论文：分数在2-10分不等（其中2分很容易，参与一个项目就可以加分了）
4、比赛获奖：分数在0.1-5分不等
5、其他加分项：如参军，发明专利等
总体而言我们可以发现，科研论文的加分是相对容易的，在奖学金里面一等奖才能加2
分，参与一个科研项目也能加2分，明显后者更容易一些。
而且我们知道，保研直博都是竞争极为激烈，大家成绩都差不多，最后都要看各项加分

第三，招你的导师看重科研经历
无论你是参加推免夏令营，还是九月份的正式推免，简历筛选是必经的考验。而简历的筛选者，大多都是该高校学院里的
导师们，那导师们都看重些什么呢？除了你在本校的排名之外，本科阶段的科研经历也是导师们特别关注的。这主要是因为研
究生阶段主要是以从事科研工作为主，需要拥有提出问题、独立分析和解决问题的能力，本科阶段有相关科研经历必定会对未
来的研究生生活起到一定的帮助。导师通过与学生交流参加科研活动的体会，来考察一个学生对待科研的态度和是否适合从事
自己的研究方向，这点对于有意向申请直博的学生更为重要。在交流的过程中，导师也可以大体了解学生对专业相关基础知识
的掌握情况。因此如果你在本科阶段就有了科研经历，在推免申请中无疑是很好的一个亮点。

对申博的帮助
1、个人信息表
一般是自己的情况介绍，包括年龄、民族、出生年月、本科研究生毕业证书相关信息等。
2、个人学习及研究经历
这个内容一般包括个人学术及学术研究经历、在学期间取得的成就、报考动机、未来发展构想等等。一般没有
具体模板，申请者自行撰写即可。
3、科研情况以及学术论文代表作汇总
这些如是撰写就可以了，一般申请者的主要学术背景资料会在网上公开，所以申请者在撰写时，一定要保证真
实性。有意走申请-考核制读博的同学，要知道科研论文才是最好的"硬通货"，因为没有论文，是通不过资格
审查环节的。
1、笔试环节：有的院校没有这个环节，有的院校有。如果要报读的院校有笔试环节的话，申请者除了做好专
业知识的复习之外，还要做好长时间作答试卷的准备。一般笔试环节持续时间长2-4小时不等。
2、面试环节：当通过一系列资格审核后，很多院校会组织专家评委对报考者进行面试考核。申请考核制下答
辩成绩还是很重要的。对于这种一人面对诸多导师的答辩现场，报考者一定要自信从容，保持仪态整洁大方，
回答评审专家问题时，真诚专注，切忌不懂装懂。

后续环节注意事项

影响因子解释（IMPACT FACTOR，缩写IF）
影响因子越高越好，小于0.5价值比较有限
影响因子是美国科学情报研究所（INSTITUTE FOR SCIENTIFIC INFORMATION，简称ISI）每年出版的《期刊引用报                 
告》（JCR，全称JOURNAL CITATION REPORTS）上的一项数据，指的是某一期刊的文章在特定年份或时期被引用的频
率，是衡量学术期刊影响力的一个重要指标。
期刊发表注意事项影响因子=该刊前2年所发表的论文在第3年被引用的次数/该刊2年内所发表的论文总数。
举例来说，某期刊2018年影响因子的计算方式为：
·本刊2017年的文章在2018年的被引次数：48；本刊2017年的发文量：187；本刊2016年的文章在2018年的被引次数：
128；本刊2016年的发文量：154
·本刊2016-2017的文章在2018年的被引次数总计：48+128=176；本刊2016-2017年的发文量总计：187+154=341；本刊
2018年的影响因子：176÷341=0.5161

1、要明确发表的用途，选择合适的期刊。作者指南中往往刊载了许多期刊的详细信息：如期刊提交论文的要求，期刊

学术论文的常见分类
COMMON CLASSIFICATION OF ACADEMIC PAPERS

2.综述型论文(REVIEW PAPER)
研究型论文是最常见的一类期刊论文，在期刊中通常占据大量篇幅。研究型论文的特点是针对某一个(些)问题，分析和讨论原
创性研究发现，其主体部分的常规格式为研究问题及其相关内容介绍(前言)，研究方法，研究成果，讨论以及总结。论文字数
一般在5000~8000个单词(根据具体期刊要求)。
研究型论文的其他英文描述:
Original Paper, Original Articler Article, Standard Paper
综述型论立是对已有研究的综合评价或对当前研究进展的考察来澄清问题，会引用某个领域50~100篇(甚至更多)文献参考资
料，来辨明其中的关系，矛盾，差距及不一致性，并建议解决问题的后续步骤。该类型论文不要求作者对其研究发现进行阐
述，因此这类论立一般在项目初期通过大量的文献资料研究进行撰写。
综述型论文通常细分成以下三类:
(1)文献综述:标准的综述型论文，对某一领域，某一专业或某一方面的文献资料进行综合性介绍和阐述;
(2)系统综述:就某一个研究问题参考重要的研究文献，其他综述论文和灰色文献，从而更系统，更有针对性地提出解决方案;
(3)元分析:采用统计学方法就某一个研究问题从若干个相似的调查研究中分析结果。
综述型论文的其他英文描述:
Overview Paper, Survey Paper

3.方法型论文(METHODS PAPER)
方法型论文旨在展示一种新的实验方法、测试方法或者流程，对结果不做过多阐述。
其架构和篇幅与研究型论文相似。尽管结果不是这类论文的核心部分，但大部分期刊仍会要求提供结果相关的数据样本。
研究型论文的其他英文描述: 
Experimental Paper
4.讨论型论文(DISCUSSION PAPER)
讨论型论文是在已公布的研究中通过阐述，分析或研究方法展示作者的观点，是基于证据的建设性评论报告。该类论文也允许
作者提出新的假设或对已公布的数据提出新的阐释。通常作者的研究成果不会披露到该类论文，论文字数在2000~4000个英文
单词。
讨论型论文的其他英文描述:
 Perspective Paper, Hypothesis Paper,Opinion Paper, Commentary
5.简报型(SHORT COMMUNICATION)
简报型论文以较短篇幅展现某个课题或研究方向的最新进展，实效性较强，字数限制在1000~3000个英文单词文字风格和文本
结构与研究型论文类似。
简报型论文的其他英文描述: 
Letters,Rapid Communication, Brief Communication, Short Reports, Brief Reports, Micro Article, Research Note

最基础的论文研究方法
THE MOST BASIC THESIS RESEARCH METHOD
ACADEMIC RESEARCH WHITE PAPER
一、文献研究法
这是基本法、通用法。对于99.9%的学生来说只要写论文都需要站在巨人肩膀上，因此文献研究法就是这个意思，先
梳理前人的研究，然后形成自己的论文写作思路。
二、案例分析法
较为常见，也算基本法之一。建议大家在选题中一定要选择小而具体的研究对象，用具体的案例去研究去佐证去发现
问题最后提出对策。
三、问卷调查法
通过书面语言与被调查者进行交流，来搜集研究对象具体情况的方法。例如《XXXX现状调查与分析》《XXXX活动研
究调查》等类似的题目，问卷调查法就是为他们量身定做的。
对某些特定对象的采访谈话。选择一个对象去问他关于课题的内容，得到一些讯息，反馈到你的论文中。在了解研究
对象的基本情况时可以打听一下它的现状，而有条理目的的“打听”就是访谈。此外我们也可以请教领域专家，行业
领袖，企业领导等谈谈相关研究课题中的一些问题，他们的言辞都可以被记录下来合理运用到你自己的论文中。
四、访谈法
官方解释是对物与物之间和人与人之间的相似性或相异程度的研究与判断的方法。在论文中也不少见。大家课题研究
中只要包含了一些对比，比如A产业的A公司的数据可以拿A产业的B公司的数据比较，这就体现了比较分析法。大家
举一反三使用即可。

### ⭐ 硬指标（T2/T3，全部可量化）

| 项目 | 要求 |
|---|---|
| **轴距** | **≥ 1525 mm** |
| **轮距** | 较小轮距 ≥ 较大轮距的 **75%** |
| **轮辋直径** | **≥ 203.2 mm**（8 英寸） |
| **最小静态离地间隙** | **≥ 30 mm**（有车手时，除轮胎外任何部分） |
| **悬架跳动行程** | **≥ 50 mm**（有车手时） |
| 转向自由行程 | **≤ 7°**（方向盘测量） |
| **后轮转向角** | 允许，但须机械限位在**最大 6°** |
| 雨胎花纹深度 | **≥ 2.4 mm** |
| 车身边缘圆角 | ≥ 1 mm（可能与行人接触处） |
| 低压系统电压 | 最大 **60 VDC / 50 VAC RMS** |
| 主开关把手 | ≥ 50 mm 宽，红色可移除，机械旋转式 |
| 举升点 | 橙色，外径 25–30 mm 圆铝/钢管，裸露段 ≥ 280 mm，管底离地 ≥ 75 mm |
| 溢流罐 | ≥ 液体体积 10% 且 ≥ 100 mL（取大者） |

**车手逃生时间**（T5.8）是技术检查必测项。检查分三段：第一车检（电气/机械/无人驾驶系统）→ 第二车检 → 第三车检（噪声、主开关、鸣笛、雨淋、制动）。

### 有效锁紧机构（T11.2，工程细节）

**认可**：锁紧线、开口销、尼龙防松螺母（>80°C 禁用）、预置扭矩式螺母、锁紧片、带耳止动垫圈
**不认可**：弹簧垫圈、尼龙防松螺栓、Loctite 螺纹胶

## 四、⚖️ FSC vs RoboMaster 赛制对比

| 维度 | **FSC（大学生方程式）** | **RoboMaster（机甲大师）** |
|---|---|---|
| 主办 | 中国汽车工程学会 | 大疆 DJI / 组委会 |
| 载体 | **一台车**（单人座方程式赛车） | **一队机器人**（7-8 台） |
| 对抗形式 | **计分制**（各自跑，按时间/表现换算分数） | **实时对抗**（同场 7v7，打基地） |
| 胜负判定 | **累计总分**（1000 分） | 打掉对方基地 / 血量多者胜 |
| 核心能力 | 车辆设计、制造、成本控制、商业营销、沟通协调 | 机器人研发、战术、临场调度、团队协同 |
| 静态项目 | **325 分**（设计/成本/商业报告） | 有赛季规划、技术评审文档，但**不计入比赛分** |
| 动态项目 | 675 分（直线/8字/避障/耐久/效率） | 单场比赛内完成攻防 |
| 耐久权重 | **极高（300/1000）** | 无对应项（考验单场稳定性） |
| 技术门槛 | 机械+动力+空动+电气（汽车工程全链） | 机械+电控+视觉+AI+软件 |
| 学科对口 | **车辆工程、汽车工程、机械** | 自动化、电子、计算机、AI |
| 单赛季节奏 | **一年造一台车**（设计-加工-装配-测试） | 赛季内多场比赛，机器人迭代 |
| 关键差异 | **商业报告/成本分析占 175 分** —— 工程 + 商科复合 | 无商业维度，纯技术对抗 |

**一句话**：RM 是**"竞技体育 + 机器人"**，FSC 是**"工程项目管理 + 赛车"**。FSC 更贴近**真实车企的研发流程**（要交设计报告、成本清单、商业方案），RM 更贴近**技术对抗与算法**。

## 七、给用户的判断

**1. FSC 和 RM 是两条完全不同的路**

- **吉甲大师（RM）**= 机器人对抗，走自动化/电子/计算机方向，跨校区（南湖）
- **吉速（FSC）**= 造一台方程式赛车，走**车辆工程/汽车工程**方向，**同校区（南岭）**

对"转车辆工程"这个目标，**FSC 的对口度远高于 RM**。FSC 考的就是你要学的专业课：汽车构造、汽车理论、底盘设计、空气动力学。

**2. FSC 有 175 分是"商科分"**（商业报告 75 + 成本分析 100）

这意味着车队里**不只招工科生**——营销组、成本组、商业报告组都需要人。**如果你的技术基础暂时不够，从商业报告/成本分析切入是真实可行的路径**，而且这部分分值不低（175/1000）。

**3. 耐久测试 300 分是胜负手**

吉速 2025 年拿下耐久第 1，说明**可靠性工程做得好**。这也是转专业后最实用的能力——真车企最看重耐久与可靠性。

**4. 门槛比 RM 低**

- FSC 静态项目（设计/成本/商业报告）**可以新人深度参与**，不需要先会做机器人
- 2026 年 5 月郑州赛，吉速"**派出全部车手此前均未参加过正赛**"，说明新人上手渠道成熟

**5. 时间上你能做什么**

| 现在（9月） | 10-11 月 | 寒假 | 大一下 |
|---|---|---|---|
| 读 2026 规则最终版（198页） | 关注纳新 | 车架/空动基础 | 争取进队参与 2027 赛车设计 |

**建议优先读**：`2026中国大学生方程式系列赛事规则（最终版）.pdf` 的 **T2、T3、T7、T9、第七章 S** 这几节——分别是尺寸、底盘、制动、空动、静态项目评分。这五节决定"一台车要满足什么"和"分从哪来"。

### ⚠️ 本次踩的坑（已修复，记录备用）

1. **urllib 不会自动 percent-encode 中文/空格 URL** → 报 `UnicodeEncodeError: 'ascii' codec` 或 `InvalidURL: control characters`。必须 `urllib.parse.quote` 分段处理。
2. **Windows 终端 GBK，`print()` 中文可能崩** → 输出用 `s.encode("ascii","replace").decode()`。
3. **PowerShell 重定向 `>` 会把 UTF-8 转成 UTF-16** → 中文全变豆腐块。**必须让 Python 自己写文件**。
4. **整站重爬 + 下载混在一个脚本会超时** → 拆成"抓清单（存 JSON）"和"读 JSON 下载"两步，下载用 `ThreadPoolExecutor` 并发。
5. **Bing `site:` 语法在国内站已失效**，返回无关结果。
