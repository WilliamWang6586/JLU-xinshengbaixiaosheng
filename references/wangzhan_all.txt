## 校园网使用指南（南岭校区重点，2026-08 整理）

### 资费与开户
- 20 元/月/IP，不限国内流量；2月、7月免费；开户需校园卡余额≥100元、预缴5个月
- 开通有线 IP 后，全校 WiFi 免费

### 账号体系（新生易混淆）
- 自助营业厅（缴费/变更MAC/销户）：ip.jlu.edu.cn/pay/，登录=一卡通卡号+身份证后6位
- 上网认证（客户端/Portal）：吉大邮箱账号（去掉@jlu.edu.cn）+邮箱密码，不是学号、不是一卡通密码
- 客户端下载：login.jlu.edu.cn

### WiFi
- JLU.WIFI：手机/平板，网页Portal认证，弹不出页面手动打开 https://net.jlu.edu.cn
- JLU.PC：电脑，必须装官方客户端登录
- 全校区漫游可用，离校失效；同时在线上限 1台PC+2台移动设备，超限踢下线
- 无线带宽约40Mbps，宿舍晚高峰拥堵，大负载走有线

### 宿舍有线网（南岭）
- 每寝室墙面2个带D标识网口；1网口绑定1个IP账号，自备超五类/六类网线
- 开户填：南岭校区+公寓+寝室号+有线网卡MAC地址（ipconfig /all 查物理地址）
- IP必须自动获取，禁止静态IP；DNS官方 10.10.10.10，备用 114.114.114.114
- 换电脑/换宿舍必须去自助平台做【变更MAC】或网络迁移，否则断网
- 🔴红线：禁止路由器WAN口NAT共享单IP多设备（会封禁）。合规折中：路由器当交换机/AP，网线插LAN口、关DHCP，每台设备各自登录独立账号

### 网络限制与境外站点访问（重点）
- 宿舍A类学生IP无国际出口，校园网不能直接访问境外站点（GitHub/Steam国际服等）
- 校内资源（知网/图书馆/教务）校园网直连；校外访问校内资源用吉大WebVPN vpn.jlu.edu.cn（校内开反而异常）
- 不要篡改网卡MAC地址，会直接断网
- 校园网内禁止第三方VPN/代理/Clash/加速器，锐捷检测到虚拟网卡或系统代理会强制下线

### 合规访问 Steam/GitHub 方案（2026-09-13 实测更新）
1. Steam → Watt Toolkit（原Steam++）只开【Hosts加速】指向国内CDN，禁止开系统代理模式
2. GitHub → **ghproxy.net 前缀法**（任意 github 链接前加 `https://ghproxy.net/`）：
   - clone：`git clone https://ghproxy.net/https://github.com/用户/仓库.git` ✅实测通过
   - Release/raw：`https://ghproxy.net/https://github.com/.../releases/download/...`
   - 备选加速站：gh-proxy.com、ghfast.top
   - ⚠️ kgithub.com 镜像已失效（2026-09-13 实测超时），勿再使用
   - ⚠️ ghproxy 只放行 github 域名，转发其他站点（如 arxiv）返回 403
3. 兜底 → 手机热点（仅小流量场景：clone、验证）
- ⚠️踩坑：Watt Toolkit 与本地代理软件（Clash等）不能同时开，会扰乱网络路径导致其他应用断连
- ⚠️踩坑：arvix/V2EX/36kr 等境外站校园网直连不通，且无可用镜像（ghproxy 不放行）

### 常见故障排查
1. JLU.PC认证超时/登录失败：关闭所有代理、VPN、虚拟网卡→重启客户端
2. WiFi无登录弹窗：手动访问 net.jlu.edu.cn，关闭私人DNS、代理
3. 频繁被踢下线：检查在线设备列表踢陌生设备，修改吉大邮箱密码
4. 有线网口不通：确认自动获取IP→核对登记MAC→换网线/网口→对比室友判断端口故障
5. 游戏/下载慢：切有线直连，避开20-23点晚高峰
