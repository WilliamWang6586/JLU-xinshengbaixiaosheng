1. `Expand-Archive` 解压到 `$env:TEMP\fs_stage`，**不要解压到用户桌面**（305MB + 47 张照片会糊满桌面）。
2. 桌面零散附件按题目归属塞进对应车队的 `附件\` 子目录，并**另存一份可读命名副本**（原名"附件二动力总成组第3题文档.pdf"看不出来是 KTM690 手册）。

### 6.3 配图：不要指望 AutoCAD

纳新题里的「建模题」要求 stp + 自带 U 盘。本机只有 AutoCAD 2027、**无 CATIA/SolidWorks**，且实测 `PlotToFile` 返回 True 但不出文件、`Export(...,"PNG")` 不可用、`-PLOT` 经 SendCommand 会卡死并把 CAD 拖进模态忙状态（之后所有 COM 调用抛 `<unknown>.xxx`）。

**结论：几何用 Python 算 + matplotlib 出图（png 300dpi + svg 插 Word），DWG 用裸 win32com 画，stp 交不了就直接说交不了。** 用 U 盘打开发现是假模型比不交更糟。

裸 COM 画自定义曲线的正确写法（VARIANT 是最大坑）：

```python
from win32com.client import VARIANT; from array import array
VT_ARRAY, VT_R8 = 0x2000, 5
P3 = lambda x, y, z=0.0: VARIANT(VT_ARRAY | VT_R8, array('d', [x, y, z]))
ms.AddLine(P3(0,0), P3(10,0)); ms.AddCircle(P3(cx,cy), r)
ms.AddPolyline(VARIANT(VT_ARRAY | VT_R8, flat_xyz))   # 扁平，每点带 z
```
`VARIANT(0, 2, (x,y,z))` 必报 `TypeError: __init__() takes 3 positional arguments but 4 were given`。
CAD 未启动时 `Dispatch` 不报错，首次访问属性才抛 `AttributeError: AutoCAD.Application.Documents` —— 那是没进程，不是代码错。

**几何正确性用断言验，不要看视觉模型的判断**（本次视觉模型对着正确的图连报「齿对穿、只画了局部」，白改一轮）：

```python
assert abs(a - (d1+d2)/2) < 1e-12            # 中心距
assert abs(prof[:,0].max() - ra) < 1e-6      # 齿顶半径
assert len(polylines) == z1 + z2             # 齿廓条数 = 齿数
dmin = np.hypot(A[:,None,0]-B[None,:,0], A[:,None,1]-B[None,:,1]).min()  # 最小距离判相切
```

齿轮专属坑（本次踩穿）：
- **相位**：`one_tooth()` 生成齿关于 +x 对称；从动轮在右侧时它的**齿槽**要朝 −x，整体相位 `π + π/z`，写成 `π/z` 是半齿距 → 齿偏到一整个 2r 之外，看上去"两轮不接触"。
- **放大倍数先算**：`视野半宽 = W_display / K` 必须 ≈2~3 个齿距且 > 全齿高。m=2（齿距 6.28、齿高 4.5）时 K 只能取 3~5；取 K=22 视野 ±1.36 mm，一条齿都进不去。
- **matplotlib 中文**：`plt.rcParams["font.sans-serif"]=["Microsoft YaHei","SimHei"]`；**`₁₂` 下标字符雅黑无字形，静默变方块**，用 `d1`/`d2` 或 mathtext `$d_1$`；参数表类文本别用 `family="monospace"`（落 DejaVu，中文全丢）。
