# 吉大就业网职位数据抓取（jdjyw.jlu.edu.cn）

用于回答「XX 专业就业方向/薪资如何」「往年就业数据」。**吉大不按专业公布就业去向**，
唯一可实测的替代品是在架招聘岗位数据。

## 一、关键事实（先说结论，别浪费用户时间）

- 吉大官方**未按专业**公布毕业生去向；全校就业质量报告仅到 2023/2024 届且是全校口径。
- 「某专业毕业生去了哪」拿不到 → **明说拿不到**，不要编造院校分布或薪资。
- 可用替代：抓就业网**在架职位**，得到「市场上有什么坑」+ 真实薪资区间。
- 另一条路：找辅导员要学院内部推免/就业统计。

## 二、抓取方法（唯一可行的路径）

列表页 `https://jdjyw.jlu.edu.cn/portal/jyzp/job/list`，**服务端渲染**，GET 翻页：

```
https://jdjyw.jlu.edu.cn/portal/jyzp/job/list?pageNo=N&pageSize=20&jobType=&categoryCode=&keyword=<URL编码>
```

- 首页 HTML 里搜 `共 N 条` 拿到总数，按 `len >= N` 停止翻页。
- 每页 `pageSize=20`，间隔 0.3~0.5s。191 条约需 10 页。
- 职位类别下拉的 `categoryCode` 可选：贸易/物流/采购/运输类、机械/仪器仪表类、
  工厂生产类、电气/能源/动力类、技工类、科研类 等。

**踩过的坑**：
- 直接 POST `/portal/jyzp/job/list` **返回整页 HTML 不是 JSON**，别当 API 用。
- 浏览器里 `page(n, size, '')` 这个 JS 函数才是真翻页入口，它跳到带 `pageNo` 的 GET URL。
- 列表页 `下一页` 的 `href` 是 `javascript:`，无法直接取链接。
- URL 里塞 `page=2` **无效**，参数名必须是 `pageNo`。
- 浏览器 `browser_console` 传复杂 JS 时，PowerShell 会吞括号/引号导致 SyntaxError
  → 改用 `Array.from(...).filter(function(a){...})` 这种无箭头函数、少嵌套的写法。

## 三、解析要点

每个岗位在 `<li>` 里，字段是 `<h6>字段名</h6><某标签>值</某标签>`：

```python
d = {}
for k in ['公司名称','公司性质','公司行业','职位性质','工作地点','学历要求','招聘人数','职位类别','专业要求']:
    m = re.search(k + r'</h6>\s*<[^>]*>([\s\S]{0,150}?)</', blk)
    d[k] = re.sub(r'\s+', ' ', re.sub(r'<[^>]+>', '', m.group(1))).strip() if m else ''
sal = re.findall(r'(\d+\.?\d*k\s*[～~]\s*\d+\.?\d*k)', blk)  # 薪资
```

`title` 取 `<h2>`。按 `(title, 公司名称)` 去重——同一公司会拆成多个岗位。

## 四、分类过滤（决定数据可信度，必做）

关键词抓取会混入大量误命中。必须按公司+岗位名做白名单/黑名单：

- **汽车产业链**：`汽车|车业|整车|底盘|三电|电池|新能源|零部件|制动|变速|智能网联|自动驾驶|物流|运输`
  排除 `生物|医药|临床|化学|环保|地基|市政|家电|食品|农药`
- **交通工程**：`交通|公路|道路|市政|桥梁|隧道|轨交|设计院|勘察|规划|交通投资|地铁`
  排除 `生物|医药|食品|酒店|银行|保险`
- 关键词「检测」误命中率极高（生物检测、化学检测、地基检测），必须二次过滤。

**异常值剔除**：标注 50–80k 的应届本科设计岗（南昌建投）疑为年薪或证书补贴口径，
不纳入统计，并在报告里注明。

## 五、统计口径

- 薪资取区间中值 `(low+high)/2`，报**中位数 + P25/P75**，不报平均数。
- 必须分学历报：本科中位 / 硕士中位 → 得出学历溢价。
- 检查单一单位批量招人导致的偏差（交通工程 57 条里 21 条来自广西交投 = 37%），
  剔除后要说「样本只剩 N 条」。
- 报「本科岗位占比」和「博士岗占比」，能看出读研必要性。

## 六、交付格式（用户偏好）

1. 开头一句大白话结论（如「交通工程比汽运窄，也比汽运便宜」）。
2. 薪资表：学历 × 样本 × 中位数 × P25/P75。
3. 岗位职能分布表（研发/质量/生产/销售/售后各多少条）——比薪资更能说明"进去了干什么"。
4. 本科可投岗位样例表（岗位|公司|地点|薪资）。
5. **数据边界**单独一节：这是在架岗位，不是毕业生去向。
6. 完整数据存 `02_吉林大学\吉林大学相关文件\就业\<方向>就业数据_实测.md`。

## 七、已跑出的结论（2026-10-30，可复用）

| 方向 | 相关岗位 | 本科中位 | 硕士中位 | 学历溢价 |
|---|---|---|---|---|
| 汽运（汽车链） | 165 | 10.5k | 14.2k | +3.7k |
| 交通工程 | 57 | 8.5k | 12.5k | +4.0k |

- 汽运本科主战场是**质量（SQE/过程质量）**，不是售后维修——售后岗位全站只有 2 条。
- 交通工程主战场是**设计院/交投**，本科 7–12k，智慧交通（算法）是唯一高薪分支 12.5k。
- 研发岗本科基本进不去，74 个研发岗多为硕士 + 算法/嵌入式方向。
