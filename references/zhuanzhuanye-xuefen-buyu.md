# 转专业学分认定与补课量（"三笔账"框架）

> 建立 2026-10-13 ｜ 数据源：《吉林大学本科学生转专业工作管理办法（2025）》（`政策文件\`）、车辆工程2026版培养方案、`各专业培养方案\专业培养方案对比.md`
> 用途：回答「这学期不学 → 转专业后要不要补 / 落下多少 / 比别人少学」类焦虑问题的标准框架

## 三笔账框架（先答资格，再答学分，最后答补课）

1. **门槛账（最致命）**：GPA≥3.0 + 排名前30% + 微积分BⅠ笔试（考的就是**本学期正在上的课**，3-5月考）。「这学期不学」不是补课问题，是**资格直接没了**。微积分BⅠ三重身份：笔试考纲 + 两边必修 + 4.5学分GPA大头。
2. **学分账（几乎不亏）**：大一上 27.5 学分 → **26.5 学分两边都是必修、100%认定**（微积分/英语/思政/体育/军理/军训等公共课）；只有 交通运输工程导论(1分) 作废——政策第二十三条(三)规定新生研讨课/学科导论课成绩变更为无效，须在新专业重修。
3. **补课账（只有~3学分）**：错过车辆工程大一上专业课 = 工程制图A上学期段(~2分) + 机械CAD基础I(1分)；导论课本来就要重修、不算额外吃亏。车辆总学分 158 < 交通运输 169，**11分缓冲完全覆盖**这3分。

## 政策依据（校发〔2024〕201号 第五章 = 2025版管理办法第二十一~二十三条）

- 第二十一条：转入后按新专业培养方案修读；此前已开设而未修/学分无法置换的 → **学生自行补修**
- 第二十二条：可自愿申请对原专业课程做学分置换
- 第二十三条 五类处理：
  1. 完全相同或可置换 → **必须**保留或置换
  2. 内容/学时/学分不符新专业要求 → 可视为无关
  3. **新生研讨课、学科导论课成绩变更为无效，须重新修读**
  4. 无关且不愿意保留 → 可申请成绩无效
  5. 无关但自愿保留 → 保留，课程性质变选修
- 受理时间：转入新专业当学期完成，截至期末考试周开始前

## 答话模板

- 结论先行：「时间差存在但只有~3学分，大二一学期消化；真正的风险是这学期GPA/笔试，不是补课」
- 给三笔账表格（门槛/学分/补课），每笔给**具体数字**（27.5→26.5认定、1分导论作废、3分补课、158vs169缓冲11分）
- 落点行动建议：微积分往死里学，其他课稳住别拖GPA；工程制图等转成功后大二零碎时间补
