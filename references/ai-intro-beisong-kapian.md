## 第2章 计算机基础

### 1. 进制转换（★计算题必练）

- **R 进制 → 十进制**：权展开法（数码 × R^i）
- **十进制 → R 进制**：整数"**除 R 取余**"（余数倒序）；小数"**乘 R 取整**"（整数正序）
- **二 ↔ 八 ↔ 十六**：1 位八进制 = 3 位二进制；1 位十六进制 = 4 位二进制

| 二进制 | 000 | 001 | 010 | 011 | 100 | 101 | 110 | 111 |
|---|---|---|---|---|---|---|---|---|
| 八进制 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

十六进制：0-9、A=10…F=15

### 2. 信息编码

- **ASCII**：单字节，覆盖英文/符号；**Unicode**：全球字符；**UTF-8**：最常用变长编码
- 编码只让计算机"识别"符号，**"理解"含义靠向量化**

### 3. 向量与矩阵

- 向量 = 多维度特征表示；矩阵 = 向量的批量存储（m×n = m 行对象 × n 列维度）
- 内积（点积）、长度（模）；图像=像素矩阵（彩色 RGB 三通道）

### 4. 硬件体系（★）

- **冯·诺依曼五大部件**：运算器、控制器、存储器、输入设备、输出设备
- 运算器+控制器 = **CPU**；数据流/指令流/控制流
- **CPU**（通用串行调度）vs **GPU**（海量并行，擅长矩阵运算）vs **AI 芯片**（TPU/NPU 专用优化）
- 存储分层：寄存器 > 缓存 > 内存(RAM) > 外存(HDD/SSD)（越近越快越小越贵）
- 存储单位：1024B=1KB → 1MB → 1GB → 1TB

### 5. 软件

- 系统软件（操作系统/驱动/数据库）vs 应用软件（办公/图像/行业）

## 第3章 Python 编程基础（题量最大，占题库 71%）

### 1. 数据类型特性（★判断题最爱考）

| 类型 | 界定符 | 有序？ | 可变？ | 可重复？ |
|---|---|---|---|---|
| 列表 list | `[]` | ✅ | ✅ | ✅ |
| 元组 tuple | `()` | ✅ | ❌ 不可变 | ✅ |
| 字符串 str | `''`/`""` | ✅ | ❌ 不可变 | ✅ |
| 字典 dict | `{}` | ❌ 无序 | ✅ | 键唯一 |
| 集合 set | `{}` | ❌ 无序 | ✅ | ❌ 元素唯一 |
| 布尔 bool | True/False | — | — | — |

**易错**：字典的"值"可重复、"键"唯一；集合元素不能是列表（不可哈希）；元组比列表快。

### 2. 运算符（★）

- 算术：`+ - * /`（真除法）`//`（整除）`%`（取模）`**`（幂）
- 比较：`== != > < >= <=`
- 逻辑：`and or not`
- 优先级：**括号 > 幂 > 乘除模 > 加减 > 比较 > 逻辑**
- 复合赋值：`x += 6` 等价 `x = x + 6`；`x /= x*y+z` 等价 `x = x/(x*y+z)`

### 3. 内置函数（★高频）

`len()` `sum()` `max()` `min()` `round()` `abs()` `range(a,b)`（含 a 不含 b）`enumerate()`、类型转换 `int() float() str()`
- `input()` 返回**字符串**（★判断题必考）
- `randint(1,100)` 可能取到 100（含两端）

### 4. 流程控制（★）

- 分支：`if / elif / else`（冒号不能少，语句要缩进）
- 循环：`for i in range(...)`、`while 条件`
- `break`（跳出整个循环）vs `continue`（跳过本次，进入下一轮）★
- 列表推导式：`[x**2 for x in range(10) if x%2!=0]`

### 5. 函数与类

- 定义 `def 函数名(参数):`，返回 `return`；匿名函数 `lambda`
- 类：`class` + `__init__(self,...)` 构造；实例方法第一个参数 `self`
- 实例化 `对象 = 类名()`；默认参数（未传用默认值）

### 6. 文件操作（★题库最大单一考点）

- 打开 `open(文件名, 模式)`，模式：`r`读 `w`写(覆盖) `a`追加
- 读取 `read()` `readline()` `readlines()`；写入 `write()`
- 用 `with open(...) as f:` 自动关闭

### 7. 异常与模块

- `try / except`：`ZeroDivisionError`（除零）、`ValueError`（类型转换失败）、`TypeError`（类型不匹配）、`IndexError`（索引越界）
- 导入：`import 模块` / `import 模块 as 别名`（如 `import numpy as np`）/ `from 模块 import 函数`
- 标准库（random、math）vs 第三方库（numpy、pandas，需 pip install）

### 8. 常用库

- **NumPy**：ndarray 多维数组、矢量化运算（np.array、.shape、.sum、.max、.dot）
- **Pandas**：DataFrame（二维表）、Series；read_csv、.head、.info、.describe、.drop
- **Matplotlib**：plt.plot 折线、scatter 散点、bar 柱状

## 第4章 机器学习

### 1. 定义与术语

- **Tom Mitchell 定义**：程序在任务 T 上，性能 P 随经验 E 提升
- 术语：样本、**特征**（描述样本的属性）、**标签**（真实输出）、模型、**参数**（学出来的规律）vs **超参数**（人为设定的规则，如学习率/迭代次数/批量大小）
- 训练集/验证集/测试集**严格隔离**

### 2. 四大范式（★必背）

| 范式 | 有无标签 | 核心 |
|---|---|---|
| 监督学习 | ✅ 有标签 | 学输入→标签映射（分类/回归） |
| 无监督学习 | ❌ 无标签 | 发现隐藏结构（聚类/降维） |
| 半监督学习 | 少量有标签+大量无标签 | 结合两者 |
| 强化学习 | 奖励信号 | 与环境交互学最优策略 |

### 3. 常见算法归类（★）

| 任务 | 算法 |
|---|---|
| 回归 | 线性回归、多项式回归、岭回归、神经网络 |
| 分类 | 逻辑回归、KNN、决策树、SVM、朴素贝叶斯、随机森林 |
| 聚类 | K-Means、层次聚类、DBSCAN、谱聚类 |
| 降维 | PCA |

### 4. 关键概念

- **线性回归**：损失=均方误差(MSE)；求解=最小二乘法 / 梯度下降法
- **逻辑回归**：Sigmoid 输出概率，阈值 0.5 分正负类；损失=交叉熵
- **过拟合**（训练好测试差，复杂度过高）vs **欠拟合**（都差，复杂度过低）
- **梯度下降**：沿**负梯度**方向迭代；学习率过大震荡、过小收敛慢
- 强化学习四要素：状态/动作/奖励/策略；探索 vs 利用

## 第5章 人工神经网络与深度学习

### 1. 人工神经元与激活函数

- 神经元计算：**加权求和 + 偏置 + 激活函数** `y = f(Σw·x + b)`
- 为什么激活函数：多层线性叠加仍等价线性，激活函数引入非线性

| 函数 | 输出 | 缺点 |
|---|---|---|
| Sigmoid | (0,1) | 饱和→梯度消失 |
| Tanh | (−1,1) | 仍有饱和区 |
| **ReLU** | [0,+∞) | 负半轴恒0→神经元失活 |

- **Softmax**：多分类，输出概率分布（和为1）

### 2. 感知机 → MLP

- 感知机只能处理**线性可分**问题（死穴：XOR）
- MLP：输入层(只传不计算) + 隐藏层(特征提取) + 输出层；相邻层**全连接**
- 输出层：二分类=1神经元+Sigmoid；多分类=K神经元+Softmax；回归=不激活
- **通用近似定理**：单隐藏层+足够神经元可逼近任意连续函数

### 3. 训练与反向传播（★）

- 训练三步循环：**前向传播 → 计算损失 → 参数更新**
- 损失：回归用**MSE**（均方误差），分类用**交叉熵**
- **反向传播 BP**：用**链式法则**从输出层逐层回传求梯度（配梯度下降更新参数）
- 梯度下降类型：全批量（稳定但慢）/ SGD（快但波动）/ **Mini-batch**（最常用）

### 4. CNN（★）

- 三大灵感（Hubel&Wiesel 1959 猫视觉皮层）：**局部感受野、层级化处理、权值共享**
- 结构：卷积层(提取特征，有参数) → 激活层 → 池化层(下采样，**无参数**) → 全连接层(整合) → 输出层
- 池化：最大池化(取最大) / 平均池化(取均值)
- 发展史：**LeNet-5(1998)→AlexNet(2012,ReLU+Dropout+GPU)→VGG(2014)→GoogLeNet(2014)→ResNet(2015,残差)**

### 5. RNN / LSTM

- RNN：循环连接给"记忆"，参数共享，BPTT 训练；梯度消失(短记忆)/梯度爆炸(梯度裁剪)
- LSTM：细胞状态 C(记忆) + 隐藏状态 h(输出)；三扇门=**遗忘门/输入门/输出门**；门控用 Sigmoid(0~1 控流量)，加法路径缓解梯度消失

## 第6章 计算机视觉

### 1. 数字图像基础

- 像素：最小单元；分辨率：横×纵像素数（720p/1080p/2K/4K）
- **RGB** 三通道(0-255)，彩色图=三维矩阵；灰度图=单通道；HSV(色调/饱和度/明度)

### 2. 五大任务

图像分类(是什么) → 目标检测(是什么+在哪，边界框) → 图像分割(像素级) → 目标跟踪(视频轨迹) → 图像生成(AIGC)

### 3. 评估指标（★必背）

| 指标 | 公式 | 记忆 |
|---|---|---|
| 准确率 Accuracy | (TP+TN)/(TP+TN+FP+FN) | 整体判对 |
| 精确率 Precision | TP/(TP+FP) | "不乱说话" |
| 召回率 Recall | TP/(TP+FN) | "火眼金睛" |
| F1 | 2PR/(P+R) | 调和平均 |

- 混淆矩阵：TP/TN 对，FP 误报，FN 漏报
- **Top-1**（最高概率=真实）/ **Top-5**（真实在 top5 内）

### 4. 目标检测

- **IoU** = 交集/并集（阈值 0.5）；**NMS** 非极大值抑制去冗余框；**mAP** = 各类 AP 均值（黄金标准）
- 两阶段（Faster R-CNN，先提议后分类，精度高）vs 单阶段（YOLO/SSD，端到端，速度快）

### 5. 图像分割三类

- **语义分割**（像素分类，不区分个体）/ **实例分割**（区分同类的不同个体）/ **全景分割**（语义+实例，stuff+things）
- 经典模型：FCN、U-Net（医学）、Mask R-CNN（实例）、Panoptic FPN（全景）
